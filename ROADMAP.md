# Roadmap

AtlasWriter's releases are planned as milestones. Each major version (2.0, 3.0 and so on) ships the features listed under it.

## 2.0

- Markdown quality of life improvements:
  - Drag and drop images to link them (done in 1.3)
  - Links to external websites, with basic embedding (done in 1.3)
  - Meta blocks that set the file's metadata, for better browsing (done in 1.1.1)
  - Interactive elements in preview mode, such as checking off to-do list items (to-do lists done in 1.1)
- Workspaces for working with PDFs and EPUBs (done in 1.3)
- HTML previews (done in 1.3)
- Audio annotation (an audio player is in 1.3; annotating comes next)
- Custom color themes

## 3.0

A better programming experience, plus features for focused writing and editing.

### Programming

- Language-specific support configured through the config files
- A configurable LSP
- Error checking and breakpoints in the editor

### Writing

- A focus mode
- A plagiarism and AI check for texts and PDF files
- Backlinks, plus a simple SQLite database for working with data on your projects
